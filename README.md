# Ababil Spark - Blog Discussions

Community discussions, comments, and reactions for Ababil Spark - Blog by AbabilSpark.

Comments are powered by [Giscus](https://giscus.app) and stored as GitHub Discussions.

Blog: [code.ababilspark.com](https://code.ababilspark.com)

Discussions: [GitHub Discussions](https://github.com/AbabilSpark/discussions/discussions)

## Purpose

This repository contains only the discussions associated with blog posts.

The blog source code and content are maintained separately.

## Discussion guide

- Each blog post uses its pathname as the [Discussions](https://github.com/AbabilSpark/discussions/discussions) mapping, for example `/posts/example-post`.
- Discussions are created in the `Ababil Spark - Blog` category.
- Use the post pathname in a discussion title when creating one manually so Giscus can find it.
- Keep conversations focused on the related article, code, questions, and suggestions.
- Report unrelated or harmful content to the repository maintainers.
